# Implementation Plan: NGO Registration

**Branch**: `001-ngo-registration` | **Date**: 2026-04-05 | **Spec**: /specs/001-ngo-registration/spec.md
**Input**: Feature specification from `/specs/001-ngo-registration/spec.md`

## Summary
Implement a secure, asynchronous NGO registration flow using FastAPI and SQLAlchemy 2.0. The feature includes user creation, 6-digit OTP generation and email delivery, stateless OTP verification, and JWT-based session management. The architecture follows a strict 5-layer modular pattern to ensure scalability and ease of migration from Supabase to AWS RDS.

## Technical Context

**Language/Version**: Python 3.14+ (uv)
**Framework**: FastAPI
**Primary Dependencies**: SQLAlchemy 2.0+ (async), Pydantic v2, asyncpg, passlib[bcrypt], python-jose, slowapi, aiosmtplib
**Storage**: PostgreSQL (Supabase/AWS RDS)
**Testing**: pytest (unit & integration)
**Target Platform**: AWS (Docker/K8s)
**Performance Goals**: <200ms p95 latency for API endpoints; <10s for OTP email delivery.
**Constraints**: Strict 5-layer separation (Controller, Service, Repository, Model, Schema), async/await only, UUID primary keys, bcrypt hashing for passwords and OTPs.
